# NexaSpark storefront (web)

```bash
# from repo root
npm run serve:web
```

| Page | File |
|------|------|
| Home | `index.html` |
| Listing + filters | `products.html` |
| Product | `product.html?id=` |
| Cart | `cart.html` |

Cart/wishlist keys: `nexaspark_storefront_cart`, `nexaspark_storefront_wishlist` (migrates from old `shopsample_*` once).
