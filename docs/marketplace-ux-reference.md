# Marketplace UX reference — inspiration only

Use as a **pattern checklist** while building **your own** brand. Do not copy logos, trade dress, or proprietary assets from any site.

## Amazon / Amazon India (patterns)

- Global search + category discovery; **MRP strike** + **% off** on PDP/PLP.
- Star ratings + review count on cards; **delivery promise** badges when true.
- Breadcrumbs on PDP; **trust** chips (returns, secure payment).

## Flipkart (patterns)

- Strong **primary blue** accent (use your brand color).
- **Deals strip** / horizontal scroll for promos.
- **Sort**: price low–high, popularity, rating — common on Indian PLPs.

## Myntra / fashion verticals (patterns)

- **Trending / bestseller** badges on cards (only when data-backed).
- Image-forward cards; size/color on PDP when you sell apparel.

## Shopify-style DTC (patterns)

- Clear **Add to cart** + **sticky** checkout path.
- **Seller / brand** line on PDP for marketplace mode.

## Etsy-style marketplace (patterns)

- **Sold by [seller]** line; reviews section with policy links.

## Technical defaults (this repo)

- Locale **en-IN**, currency **INR (₹)** in `web/storefront/js/catalog.js`.
- Cart + wishlist in **localStorage** keys `nexaspark_storefront_*` (replace with API later).
